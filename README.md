# Quản lý kho

Spring Boot 4 + React 19 + MySQL 8.4.

## Quick start

```bash
# Full stack Docker
make dev

# Hoặc chạy local từng service
make infra       # MySQL
# chạy backend trong IDE
cd frontend && npm run dev
```
